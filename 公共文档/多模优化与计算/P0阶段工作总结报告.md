## 四、技术架构

### 4.1 系统架构图
```
┌─────────────────────────────────────────────────────────────┐
│                    PostgreSQL 19 Backend                     │
│  ┌──────────────┐     ┌────────────────┐                   │
│  │   ORCA       │────▶│  CustomScan    │                   │
│  │  Optimizer   │     │  (DaftExec)    │                   │
│  └──────────────┘     └────────────────┘                   │
│         │                      │                             │
│         │ PgDaftPlan IR v1    │                            │
│         ▼                      ▼                             │
│  ┌─────────────────────────────────────────┐               │
│  │         libdaft_pg_bridge.so             │               │
│  │  ┌────────────┐  ┌───────────────────┐  │               │
│  │  │ Error      │  │ Arrow C Data      │  │               │
│  │  │ Handling   │  │ Interface         │  │               │
│  │  └────────────┘  └───────────────────┘  │               │
│  │  ┌────────────┐  ┌───────────────────┐  │               │
│  │  │ IR Parser  │  │ Execution Handle  │  │               │
│  │  └────────────┘  └───────────────────┘  │               │
│  └─────────────────────────────────────────┘               │
└─────────────────────┼───────────────────────────────────────┘
                      │
                      ▼
         ┌────────────────────────────┐
         │   Daft Execution Engine    │
         │  ┌──────────────────────┐  │
         │  │ StreamingScan        │  │
         │  │ StreamingSource      │  │
         │  │ PreparedExecution    │  │
         │  └──────────────────────┘  │
         └────────────────────────────┘
```

### 4.2 数据流
1. **计划生成**: ORCA → PgDaftPlan IR v1 (JSON)
2. **计划解析**: IR → LocalPhysicalPlan (Rust)
3. **数据输入**: PostgreSQL → Arrow C Data → StreamingSource
4. **执行**: Daft engine 处理数据流
5. **数据输出**: Arrow C Data → PostgreSQL TupleTableSlot

### 4.3 关键接口

#### 4.3.1 PgDaftPlan IR v1
```json
{
  "capability_registry_sha256": "...",
  "fragment_id": 1,
  "root_node_id": 1,
  "sources": [...],
  "nodes": [...],
  "output_schema": [...]
}
```

#### 4.3.2 C ABI 函数签名
```c
// 错误处理
DpgErrorCode dpg_error_code(const DpgError* error);
void dpg_error_free(DpgError** error);
const char* dpg_error_message(const DpgError* error);

// 执行管理
DpgExecution* dpg_execution_open(const char* ir_json, DpgError** error);
ArrowImportResult dpg_execution_push(DpgExecution* exec, uint32_t source_id, 
                                     ArrowSchema* schema, ArrowArray* array, 
                                     DpgError** error);
DpgErrorCode dpg_execution_finish(DpgExecution* exec, uint32_t source_id, 
                                  DpgError** error);
DpgErrorCode dpg_execution_next(DpgExecution* exec, ArrowSchema* schema_out, 
                                ArrowArray* array_out, DpgError** error);
DpgErrorCode dpg_execution_wait(DpgExecution* exec, uint64_t timeout_ms, 
                                DpgError** error);
DpgErrorCode dpg_execution_cancel(DpgExecution* exec, DpgError** error);
void dpg_execution_close(DpgExecution** exec);

// Arrow 数据导入
ArrowImportResult dpg_import_arrow_batch(ArrowSchema* schema, ArrowArray* array, 
                                         DpgError** error);
```
